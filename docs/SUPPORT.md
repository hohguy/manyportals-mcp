# Getting help

| What                                      | Where                                                                |
| ----------------------------------------- | -------------------------------------------------------------------- |
| A bug, or something behaving unexpectedly | [Issues](https://github.com/hohguy/manyportals-mcp/issues)           |
| A question or an idea                     | [Discussions](https://github.com/hohguy/manyportals-mcp/discussions) |
| A security problem                        | Privately: see [SECURITY](../SECURITY.md). Never a public issue      |

## What to include, and what to leave out

For a bug, the useful details are your Node.js version, the command or tool call you ran, and the output of `doctor`. That output holds no tokens, but it does hold your portal
keys, their labels, your hub IDs and your file paths. Replace those with placeholders
such as `PORTAL_A`, `Example Co` and `123456789` before you post it. If you installed the Claude Desktop extension rather than building from source, run it from the extension's own folder, as [the go-live check](GO-LIVE.md) shows.

Leave out tokens, record contents, real portal keys and hub IDs. Those identify the businesses you work with. If a detail matters to the report, describe it instead of pasting it, for example "a portal whose hub ID is not set" rather than the number.

## Paid help

ManyPortals is built and maintained by hohguy. Paid help is also available for multi-portal setup, reviews and reconciliation, without merging portals into one.

Email manyportals@hohguy.com with what you are trying to do and roughly how many portals are involved. You do not need to send portal names, hub IDs or any customer data to start that conversation.
